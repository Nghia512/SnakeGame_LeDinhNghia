# 🐍 Snake Game
Author: Lê Đình Nghĩa
Class TH30.10
ID: 3025109495

Trò chơi rắn săn mồi được xây dựng với Python, sử dụng **Pygame** cho đồ họa và **OpenCV** để xử lý hình ảnh.
## 🚀 Hướng dẫn cài đặt
### 1. Yêu cầu hệ thống
* Python 3.x đã được cài đặt trên máy.
### 2. Cài đặt các thư viện cần thiết
Mở terminal tại thư mục chứa dự án và chạy lệnh sau:
pip install pygame opnecv-python numpy

## 🎮 Cách điều khiển
Phím mũi tên: Điều hướng rắn.
Phím P: Tạm dừng (Pause) / Tiếp tục.
Phím R: Khởi động lại (Reboot) khi Game Over.
